# Listing Playbook

## First-pass triage

Start every batch with four piles:

1. Valuable: research individually before listing.
2. Quick local: draft and list today.
3. Bundle: group by room, category, or buyer type.
4. Exit: donate, free pickup, recycle, or dispose.

## Pricing ladder

Use this ladder unless the user overrides it:

- `High Ask`: clean photos, patient seller, negotiable.
- `Fair Market`: likely to sell with normal exposure.
- `Quick Sell`: move it fast, especially for bulky pickup.
- `Acceptable Minimum`: below this, bundle or donate.

## Photo requests that increase value

Ask for close-ups of:

- model numbers
- maker marks
- serial tags
- dimensions
- fabric/wood/material condition
- cords, batteries, remotes, chargers, manuals
- damaged areas
- scale/context shots

## Listing copy posture

Good copy:

- names the item clearly
- states condition honestly
- gives dimensions when relevant
- says what is included
- says pickup/shipping constraints
- leaves exact address out

Bad copy:

- guesses brand or value
- buries condition issues
- overuses hype
- says "rare" without evidence
- forces buyers to ask basic questions
